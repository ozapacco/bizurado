O que é <b>permutação</b> em análise combinatória?;Permutação é a contagem das formas de ordenar todos os elementos disponíveis. Ela é um caso particular de arranjo em que todos os elementos são usados.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Permutar é reorganizar tudo. Se todos entram na fila, pense em permutação.
Por que a <b>permutação</b> é um caso particular de arranjo?;Porque no arranjo escolhemos e ordenamos parte dos elementos. Na permutação, escolhemos e ordenamos todos os elementos disponíveis.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Arranjo usa alguns. Permutação usa todos.
Qual é a fórmula da <b>permutação simples</b>?;<b>Pn = n!</b>. Usamos quando há n elementos distintos e todos serão ordenados.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Todos diferentes em fila, use n fatorial.
Quando devo usar <b>permutação simples</b>?;Use quando todos os elementos são diferentes e todos serão organizados em alguma ordem, como anagramas de palavra sem letras repetidas ou pessoas em uma fila.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Tudo entra, tudo é diferente, fatorial direto.
Qual é a relação entre <b>permutação simples</b> e <b>fatorial</b>?;A permutação simples de n elementos é exatamente n!, pois o primeiro lugar tem n opções, o segundo n menos 1, o terceiro n menos 2, e assim por diante.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Permutação simples é fatorial aplicado.
Como calcular a quantidade de formas de ordenar <b>5 elementos distintos</b>?;Use <b>5! = 5 x 4 x 3 x 2 x 1 = 120</b>.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Cinco elementos diferentes em fila geram 120 ordens.
Como calcular a quantidade de formas de ordenar <b>6 elementos distintos</b>?;Use <b>6! = 6 x 5 x 4 x 3 x 2 x 1 = 720</b>.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> 6! = 720 é número clássico de prova.
Qual é a diferença entre <b>arranjo</b> e <b>permutação</b>?;No arranjo, escolhemos e ordenamos apenas parte dos elementos. Na permutação, ordenamos todos os elementos disponíveis.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Arranjo é seleção com ordem. Permutação é reorganização completa.
Qual é a diferença entre <b>combinação</b> e <b>permutação</b>?;Na combinação, a ordem não importa. Na permutação, a ordem importa e todos os elementos são organizados.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Combinação forma grupo. Permutação forma fila.
O que é um <b>anagrama</b>?;Anagrama é uma reorganização das letras de uma palavra, formando sequências diferentes com as mesmas letras.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Anagrama é bagunçar as letras contando cada ordem possível.
Por que anagramas geralmente usam <b>permutação</b>?;Porque as letras da palavra são reorganizadas em posições diferentes. Quando todas as letras são usadas, estamos permutando os elementos.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Palavra inteira embaralhada, permutação ativada.
Quando um anagrama usa <b>permutação simples</b>?;Quando todas as letras da palavra são diferentes. Nesse caso, o número de anagramas é n!, em que n é o total de letras.<br><br><i>Fonte: Análise Combinatória – Permutação</i><hr><b>BIZU:</b> Letras todas diferentes, fatorial direto.

Qual conceito a questão dos anagramas de <b>ORDEM</b> testa?;Ela testa <b>permutação simples</b>, pois todas as 5 letras são distintas e todas serão usadas.<br><br><i>Fonte: Análise Combinatória – Exercícios de permutação</i><hr><b>BIZU:</b> Palavra sem letra repetida é permutação simples.
Como evitar erro na questão dos anagramas de <b>ORDEM</b>?;Não use combinação, porque a ordem das letras muda a palavra formada. O que é <b>permutação com repetição</b>?;É a contagem das formas de ordenar elementos quando alguns deles são iguais. Como trocas entre elementos iguais não geram nova sequência, dividimos pelos fatoriais das repetições.<br><br><i>Fonte: Análise Combinatória – Permutação com repetição</i><hr><b>BIZU:</b> Letras iguais geram contagens duplicadas. A divisão limpa essas duplicatas.
Qual é a fórmula da <b>permutação com repetição</b>?;<b>P = n! / a! x b! x c! ...</b>, em que n é o total de elementos e a, b, c são as quantidades repetidas de cada tipo.<br><br><i>Fonte: Análise Combinatória – Permutação com repetição</i><hr><b>BIZU:</b> Total em cima, repetições embaixo.
Quando devo usar <b>permutação com repetição</b>?;Use quando todos os elementos serão ordenados, mas existem elementos iguais, como palavras com letras repetidas ou números com algarismos repetidos.<br><br><i>Fonte: Análise Combinatória – Permutação com repetição</i><hr><b>BIZU:</b> Tudo entra na fila, mas tem gêmeos. Divida pelos gêmeos.
Por que precisamos dividir na <b>permutação com repetição</b>?;Porque a permutação simples conta como diferentes algumas trocas entre elementos iguais. Como essas trocas não geram resultado novo, dividimos pelas repetições.<br><br><i>Fonte: Análise Combinatória – Permutação com repetição</i><hr><b>BIZU:</b> Trocar A com A não muda nada. A divisão corrige isso.

O que é <b>permutação circular</b>?;É a contagem de formas de organizar elementos em círculo, considerando que rotações da mesma disposição não geram arranjos novos.<br><br><i>Fonte: Análise Combinatória – Permutação circular</i><hr><b>BIZU:</b> Em círculo, girar a mesa não muda a disposição relativa.

Por que a permutação circular usa <b>(n - 1)!</b>?;Porque em círculo as rotações equivalentes são contadas como a mesma disposição. Fixamos um elemento como referência e permutamos os n menos 1 restantes.<br><br><i>Fonte: Análise Combinatória – Permutação circular</i><hr><b>BIZU:</b> Fixe um, organize o resto.
